# Variance decomposition and power for Inside Job

Generated by `python3.11 analysis/variance_power.py` (batches pilot1, pilot2; 342 s). Numbers for reuse: `analysis/out/variance_power.json`.

## What the data are, and what they cannot be

- `pilot1`: 20 show games (seeds 1 to 20). Seven seats, five cheap models, two of them seated twice, moles dealt at random. One game per deal, so inside this batch the deal and the particular playing of it (the *table*) cannot be separated: "between games" below means deal plus table.
- `pilot2`: 6 finished game(s) so far, on the same seeds, seating, models and moles as `pilot1`, with one rule changed (`sabotage_target` 2 instead of 3). It is the only replay of a deal that exists, and it is confounded with the rule change.
- The benchmark is not a show game. It is a *trial*: one test model in all five crew seats (crew trial) or both mole seats (mole trial) against one fixed reference model, on the same deals for every model. **No trial has ever been played with real models.** Everything in Part B is an extrapolation from show games, made under stated assumptions, with a sensitivity range.
- Every interval marked *game bootstrap* is a 95% percentile interval from 2000 resamples of whole games (seed 20261110; one resample matrix shared by every statistic of `pilot1`).

Terms used throughout:

- *decision*: one row of the decision table (one reading, one vote, one mole-round).
- *player*: one seat in one game (a codename; one model).
- *variance component*: the part of the variance of a single decision's value that comes from one level (game, player within game, decision within player). *share* = component / sum of the three.
- *ICC (game)*: share of the game component = the correlation between two decisions from the same game but different players. *ICC (player)*: (game + player) / total = the correlation between two decisions of the same player.
- *per-game mean*: the mean of a metric over every decision of that metric in one game (for crew metrics that is all five crew seats, which is what a crew trial would score for the test model).
- *rho*: the share of the variance of per-game means that belongs to the deal, i.e. the correlation between the per-game means of two playings of the same deal. *c*: a multiplier on the per-game variance (trial noise relative to show-game noise).

### What I believe but the data do not show

- The deal share rho is probably small for Read and larger for raw Brier: Read subtracts the solver's Brier, which already absorbs how informative the deal's clues were, so what remains is mostly how this table played. If so, the paired same-deal design buys little for Read and the rho = 0 to 0.25 columns are the realistic ones. Only finished same-rule replays can test this.
- A crew trial puts five copies of one model in the crew seats. Their readings will share blind spots, which raises the per-game variance (c above 1) rather than lowering it. I would plan with c = 1 to 2.
- Getaway at the pilot's rules sits near its floor (mean about 0.06 to 0.08) and can only be powered for large differences; CLAIMS.md's own floor test (mean under 0.10 for every model) would very likely fail. The rules need to make moles stronger before Bluff can be ranked.
- The percentile interval named in docs/CLAIMS.md should be replaced by the paired t interval (or the minimum N raised to about 40), before the analysis plan is frozen.

## Part A. Variance decomposition

### A.1 Nested components

Estimator: nested (hierarchical) one-way ANOVA, method-of-moments estimates for unbalanced data (expected mean squares with the unbalanced coefficients k1, k2, k3; Searle, Casella and McCulloch 1992, nested classifications). Model: value = mean + game + player(game) + decision. A negative player estimate is set to 0 and the game component re-solved without it; a negative game estimate is set to 0. *Raw*: the values as they are. *Adjusted*: after removing round and phase means (least-squares residuals on round dummies and, for readings, phase dummies clue / whisper / discuss / vote; refitted inside every bootstrap resample). Removing round means also removes part of the between-game variance, because long games contribute more late-round decisions.

### A.2 Does the model (or seat, or speaking position) explain the between-player variance?

Statistic: the extra share of residual variance explained by the factor's levels in a decision-level least-squares fit that already has game fixed effects plus round and phase dummies (partial R-squared). Permutation test: the factor's labels are shuffled among the seats of the same role within each game (2000 permutations; a seat's decisions move together, game effects stay fixed); p = (1 + number of permuted statistics >= observed) / (1 + permutations). *Component*: the variance of the fitted level effects minus its mean under the permutations (so 0 means "no more spread than chance"), with a game-bootstrap interval (the fit is redone on each resample; the permutation mean is held at its full-data value, an approximation). *Share of player variance* = component / adjusted player variance from A.1. Speaking position = place in the round-1 discussion order (0 = first to speak, left of the first leader; 6 = the first leader).

### A.4 Design effect: what a game is worth

*m* = decisions per game (mean). *rho_w* = average correlation between two different decisions of the same game = (game component + pi x player component) / total, where pi is the share of within-game decision pairs that come from the same player. *Design effect* = 1 + (m - 1) x rho_w. *Effective decisions per game* = m / design effect; *effective total* = games x that. ## Part B. Power simulation for the trial design

**Set-up.** N deals. Each test model plays every deal twice against the reference model: once in the crew seats (gives Read) and once in the mole seats (gives Getaway and Table read). Two models are compared by the mean over deals of the paired difference of their per-deal scores (a per-deal score = the metric's mean over that game's decisions for the test model's seats). The interval is a 95% interval from resampling deals; a difference is *detected* when it excludes 0.

**Generator.** Built from the pilot's 20 per-game means (empirical distribution, not a normal). For Read, raw Brier, Table read and crew vote hit: per-deal score = model mean + sqrt(rho) x a(deal) + sqrt(1 - rho) x b(play) with a and b drawn independently from the pilot's centred per-game means, scaled so the per-game variance is c times the pilot's. The deal part is shared by two models on one deal and cancels in the paired difference, so the difference is delta + u x (z1 - z2) with u = sd(per-game mean) x sqrt((1 - rho) x c). Under this generator rho and c act only through u: every result depends on delta / u. Getaway is mostly zeros (60% of pilot games have per-game Getaway 0), so it gets its own two-part generator (below).
